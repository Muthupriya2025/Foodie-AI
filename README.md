# 🍔 Foodie AI

**Foodie AI** is an AI-powered chatbot designed to help users discover food, explore cuisines, get personalized meal recommendations, and find answers to their food-related questions.

The chatbot provides an interactive and conversational experience, allowing users to describe their cravings, preferences, or dietary requirements and receive intelligent food suggestions.

## ✨ Features

* 🤖 **AI-Powered Chatbot** — Have natural conversations about food and meals.
* 🍕 **Food Recommendations** — Get personalized suggestions based on your preferences.
* 🌎 **Cuisine Discovery** — Explore different cuisines and dishes.
* 🥗 **Dietary Preferences** — Get suggestions based on dietary requirements.
* 💬 **Conversational Interface** — Simple and interactive chat experience.
* 🔍 **Food Search** — Discover dishes based on ingredients, cuisine, or cravings.
* ⚡ **Fast & User-Friendly** — Designed for a smooth and intuitive experience.

## 🎯 Use Cases

Foodie AI can help users:

* Decide what to eat
* Discover new dishes
* Find meals based on available ingredients
* Explore different cuisines
* Get meal ideas based on dietary preferences
* Ask food-related questions
* Get personalized recommendations through conversation

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/foodie-ai.git
```

### 2. Navigate to the Project

```bash
cd foodie-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project directory and add your required API keys and configuration.

```env
AI_API_KEY=your_api_key
```

**Never commit your API keys or `.env` file to GitHub.**

### 5. Run the Application

```bash
npm run dev
```

The application should now be available at your local development URL.

## 💡 How It Works

1. 👤 The user enters a food-related question or craving.
2. 💬 Foodie AI processes the user's message.
3. 🧠 The AI analyzes preferences, context, and requirements.
4. 🍽️ The chatbot generates relevant food recommendations or answers.
5. ⭐ The user can continue the conversation for more personalized suggestions.
